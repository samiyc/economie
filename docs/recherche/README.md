# Les recherches sur l'économie

Sami (6/11/2026) : le cadrage, comme la cuisine : le modèle, la règle à battre, un prompt de recherche métier, un
glossaire et les questions. Ce dossier rassemble ce que disent les sources publiées et ce qu'elles ne disent pas.

À lire dans cet ordre :

1. [`../modele.md`](../modele.md) : les trois modèles (SIM, PC, ÉCO), les crises, les règles simples, les mesures par
   paires, le banc public, la recherche à venir, ce qu'on prend de la lib ;
2. [chiffres.md](chiffres.md) : chaque chiffre, sa source et jusqu'où elle a été lue, puis les calculs de cadrage ;
3. [glossaire.md](glossaire.md) : les mots du stock-flux, de la macroéconomie et des finances publiques, et leur nom
   dans le code ;
4. [questions.md](questions.md) : ce qui reste à trancher, pour Sami et pour un professionnel, chaque fois avec une
   recommandation ;
5. [prompt.md](prompt.md) : le prompt d'une recherche qui viserait ce qu'on n'a pas trouvé.

**La règle.** Un chiffre a sa source, ou il est écrit comme une hypothèse avec sa question. Un chiffre lu seulement dans
un résumé ou un extrait le dit, avec son statut, et se relit avant de décider quoi que ce soit. La recherche du 6/11 a
lu, par l'outil de lecture, le README et la liste des articles de `sfcr`, les pages SIM, PC et LP de MacroStat et une
conversion du document de Blanchard et Leigh ; le reste vient d'extraits de recherche. Le livre de Godley et Lavoie,
le texte de Taylor (un scan), le document de l'OCDE (403) et le texte du règlement 2024/1263 n'ont pas été lus.
